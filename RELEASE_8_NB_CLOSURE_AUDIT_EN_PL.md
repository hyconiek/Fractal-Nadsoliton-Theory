# RELEASE 8 — Strict Kernel Textbook and QW2191 Closure (EN/PL)

## Preface / Przedmowa
EN: This textbook-style release explains the strict-kernel closure and QW2191 closure in high-school physics language.
PL: Ten podręcznikowy release wyjaśnia domknięcie kernela strict i domknięcie QW2191 językiem licealnym.

## Chapter 1 (EN): Core idea 1
1. Strict kernel view: K_strict_gate controls operational amplitudes and bounded response (chapter 1).
2. QW2191 is treated as a selector-obstruction interface that forces explicit symmetry-breaking source accounting.
3. Closure claim is NB-scoped: no implicit transfer from legacy ontological roles to strict operational roles.
4. Physical intuition: think of a filter in a wave experiment; only admissible modes survive the gate.
5. Mathematical intuition: admissible transport must preserve strict invariants; violating maps are rejected.

2. QW2191 traktujemy jako interfejs przeszkody selektorowej, który wymusza jawne źródło łamania symetrii.
3. Domknięcie ma zakres NB: bez ukrytego transferu ról legacy ontologicznych do strict operacyjnych.
4. Intuicja fizyczna: jak filtr falowy; przechodzą tylko tryby zgodne z bramką.
