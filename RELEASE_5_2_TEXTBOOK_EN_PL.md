- wyprowadzone datum orientacji,
- most selektora,
- redukcję selektora,
- output selektora,
- oraz downstreamowy łańcuch kandydata domknięcia emergentnego obserwatora.

Po ludzku:
- Release 5.1 głównie porządkował frontier,
- Release 5.2 dodaje pierwszy poważny dodatni łańcuch konstrukcyjny na trasie  
  `nadsoliton -> światło -> materia -> emergentny obserwator`.

## 2) Status w skrócie (licealnie)

### 2.1 Co jest teraz mocne

1. Ścisły pakiet SM+GR z Release 5.0 pozostaje mocny.
2. Projekt trzyma już twardą dyscyplinę anty-overclaim wobec splitu kernela i obstrukcji selektora.
3. Istnieje realny dodatni tor konstrukcyjny `source -> selector -> observer-candidate`.
4. Obserwator jest teraz traktowany ściśle jako downstream, a nie jako pierwotne źródło selekcji.
5. Repo eksportuje pierwszy pełny preobserver-to-observer candidate chain w jawnej postaci operatorowej.

### 2.2 Czego nadal brakuje

1. Pełnego strict-core selector closure.
2. Pełnego discharge `QW-2191`.
3. Rygorystycznego bridge `legacy -> strict kernel`.
4. Finalnego theorem-level actual emergent-observer closure.
5. Finalnego domknięcia TOE.

- **Finalne strict-core domknięcie selektora:** jeszcze nie.
- **Finalne TOE:** jeszcze nie.

- sam **Nadsoliton** jest pierwotną informacją wszechświata w stanie solitonowym.
