    one microscopic law

spacetime” merely because the narrative used those nouns.

## 4. Two literal minimal-cost problems can be settled theoretically

GEN-676/702 penalizes changes using squared distance, KL and a memory-change
penalty. With nonnegative weights and an admissible identity, the identity
has cost0 and is a minimizer. A claim of automatic motion/organization is
not licensed by that literal cost. Unknown compulsory memory updates or
signed costs would be different premises, not a silent repair.

GEN-931/932 instead uses a state cost sum_e f(r_e) plus a squared transition
penalty. On a product edge domain it is separable. It can relax scalar
entries but does not transmit influence between edges without a supplied
coupled constraint, nonseparable term or global tie rule. These are **different
candidate costs**, not one interchangeable FIN-M0 implementation.

The exact conditional proofs are in CORE_DERIVED_BRIDGES.md. They do not
exclude every possible relational theory. They prevent generating an apparent
success by adding a triangle reward, graph, memory drive or new clock to
an unspecified old model and calling the addition a consequence.

## 6. The no-added-assumptions rule

Permitted: changing observables, deriving a generator expansion, mathematical
limits of an already defined N/g family, stopping a path at an exit as a
record/analysis operation, proving a no-go and using alternate models as
explicit diagnostics rather than adopting them as new FIN laws.

Not permitted as derivation: supplying adjacency, new storage, a complex
physical amplitude, a unitary law, a drive, an entropy reference, SI scales
or a kernel-selection principle and reporting that FIN generated it.
An incomplete definition is OPEN_MODEL, not permission to choose the missing
function. If GEN contains another fully specified old law, bind it as a
separate input before analysing it; do not stitch incompatible variants.
