## Target Meaning

This target means only:

1. the `S3` route now owns one explicit local operator target rather than only
   one abstract memory-rule target,
2. the operator must be local on the source-side patch or transported-section
   neighborhood,
3. the operator must remain pair12-inversion-sensitive,
4. the operator must carry an explicit memory-bearing nonreciprocal or
   hysteretic ingredient,
5. the operator must stay compatible with future chart-sensitive transport
   instead of collapsing back to a basis-free scalar summary,
6. the operator remains below exact bridge reduction, below lawful supplier
   status, below `T176`, below `QW-2191`, and below `QW-2580` resolution.
