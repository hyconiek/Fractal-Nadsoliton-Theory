## Theorem-level conclusion

1. `P715/N711` already shows that the minimal dual-anchor route
   `w_break ⊕ w_ref_unnormalized` recovers all-root support and one common
   section only **up to global sign**,

   cosine-axis role of `pair4`,

   `span{w_break, w_ref_unnormalized}` and shows that no noncritical sector of
   that span yields one **exact** root-independent directed section.

Therefore the strongest honest current statement is:

```text
adding an even component inside the present single-linear span is not enough
to discharge T176.
```

Within that span:

1. all noncritical sectors still support all roots,
2. some sectors recover only the current `pair4`-negated projective orbit,
3. other sectors worsen the exact split to a `pair2/pair3` negated branch,
4. no sector upgrades the projective orbit into one exact global directed
   section.

## Consequence

The next provider attack is narrowed again:

1. the remaining gap is **not** fixed by any single mixed linear weight built
   from the current exported odd/even anchor payloads,
2. the next honest strict-core attempt must therefore leave that
   single-linear-span class,
3. so the remaining live target is a genuinely new provider class
   (for example nonlinear, higher-order, or otherwise not reducible to one
   linear form in `w_break` and `w_ref_unnormalized`).

## What this theorem does not prove

`N714` does **not** prove:
