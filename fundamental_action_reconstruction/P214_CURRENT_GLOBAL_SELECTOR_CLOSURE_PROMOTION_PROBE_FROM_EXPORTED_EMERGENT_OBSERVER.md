## Goal

Test whether the already exported emergent-observer composite may now be
promoted to:

1. global selector closure,
2. global `QW-2191` discharge.

## Probe criterion

Positive status requires all of the following:

1. one admissible local positive composite is exported,
2. the local asymmetry is stable (`commit > 0`, `gap = 0`),
3. theorem-level actual emergent-observer closure is already exported,
4. the observer role is no longer downstream-only,
5. theorem-level strict-core selector closure is already exported,
6. one basis-independent global promotion witness is already exported,
7. theorem-level global `QW-2191` discharge is already exported,
8. the promotion remains kernel-split-safe.

## Non-claims

- ToE closure,
- a proof that no future failure mode can exist.
