# V3 Minimal Pair-Level Viscosity Operator Audit

Status: `PASS_PARTIAL_COMPETING_EXTENSION_HYPOTHESIS_ONLY`
Date: `2026-03-06`

## Goal

Sprawdzic, czy da sie zapisac minimalny operator lepkości/informational-viscosity bezpośrednio na
`pair1 = (c_1, s_1)`:

- bez selector-smuggling,
- bez retroaktywnego twierdzenia, ze taki operator juz istnieje w strict core,
- z jawnym rozdzialem miedzy wersja izotropowa i wersja wymagajaca anchoru.

## Pair-level carrier

Pracujemy na:

- `V_1 = span{c_1, s_1}`

z baza:

- `(c_1, s_1)`.

## Minimal admissible classes

### Class A: isotropic viscosity

The only selector-safe isotropic viscosity operator on `V_1` is

`K_visc_iso^(1) = nu_iso * I_2`

with `nu_iso >= 0`.

This class is admissible because:

- it does not presuppose any preferred orientation,
- it behaves like a damping/slowdown term,
- it is consistent with the repository motifs `lepkość`, `damping`, `tau`, `memory`.

But it cannot break the residual `O(2)` degeneracy, because it is rotationally invariant.

### Class B: anchor-imported anisotropic viscosity

A more structured candidate is

`K_visc_aniso^(1)(psi0) = R(psi0) diag(nu_parallel, nu_perp) R(-psi0)`

with `nu_parallel != nu_perp` allowed.

This class is admissible only under explicit conditions:

- `psi0` is imported as an external anchor candidate, not generated by viscosity itself,
- the lane remains `hypothesis_extension_only`,
- no claim is made that anisotropy originates from strict-core viscosity.

This class may in principle break `O(2)`, but only by relying on an already supplied anchor.

## Selector-smuggling test

The following are not admissible as a viscosity closure move:

- writing `theta*=0` directly into the operator definition,
- choosing a preferred basis direction without an exported anchor,
- calling anisotropy "viscosity" if the anisotropy itself is not explained.

## Result

The honest current state is:

- a minimal pair-level viscosity operator can be written,
- but only two admissible classes exist,
- and only the anchor-imported anisotropic class can even hope to affect selector closure.

So viscosity by itself remains weaker than the `psi0` lane.

## Frontier

`V3_B1 := a minimal pair-level informational-viscosity operator can be written on V_1, but only in two admissible classes: isotropic (which cannot break O(2)) or anchor-imported anisotropic (which depends on an external anchor and therefore does not by itself solve selector closure)`

## Hard limits

- no `theorem-level PASS`
- no `full-closure PASS`
- no claim that viscosity is already present in strict core as a selector operator
- no claim that isotropic viscosity can break `O(2)`
- no claim that the anisotropic class generates its own anchor
