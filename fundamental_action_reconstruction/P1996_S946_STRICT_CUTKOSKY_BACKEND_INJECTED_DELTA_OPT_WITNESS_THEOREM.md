# P1996 / S946 — Strict Cutkosky backend-injected Delta_opt witness

Wprowadzono pierwszy profil backendowy bezpośrednio oparty o współczynniki B1 i przeliczono `Delta_opt(s)`.

Wynik: defekt optyczny pozostaje niezerowy (kontrolowany), co daje bardziej realistyczny sygnał obstrukcji niż czysto schematyczna perturbacja.

To nadal witness proxy kanału, nie theorem-grade global closure.
