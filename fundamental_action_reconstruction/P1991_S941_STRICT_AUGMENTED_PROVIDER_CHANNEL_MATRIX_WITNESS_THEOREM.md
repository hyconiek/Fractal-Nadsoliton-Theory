# P1991 / S941 — Strict augmented-provider channel-matrix witness

Wynik: układ nie daje pełnego jednoczesnego domknięcia wszystkich kanałów (rank/LSQ residual wskazuje brak pełnego dopasowania).

To nadal świadek obstrukcji w klasie non-strict augmented.
