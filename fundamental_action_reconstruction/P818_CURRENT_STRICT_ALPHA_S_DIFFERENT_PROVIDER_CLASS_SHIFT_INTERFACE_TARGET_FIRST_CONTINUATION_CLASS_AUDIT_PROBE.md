## Goal

```text

once a different provider-class candidate lane is admitted
but the alpha_s shift interface remains blocked?
```

## Scope

`P818` does not decide whether the exact `alpha_s`-side shift interface
already exists.
It only decides the correct *class* of the next move:

```text

vs
adapter-rule / carrier-identification first
vs
some looser continuation class
```

1. confirm `F817` leaves the `T213/T216` lane at candidate-reference grade

   `interface-target first` (`F789`),

   `exact shift-interface target first` before any adapter-rule target

   (`P764` before `P765/P766`),
5. decide which move class is immediate and which classes remain premature.

## Result

`P818` returns one narrow continuation-class verdict:


not:

