## Goal

After `N306`, the new ontology-level blocker-cut is no longer just vague
language.

But it still lacks the one thing that would give it mathematical teeth:

```text
an explicit preorientation law
```

So the next honest question is narrower:

```text
can the current repo already name the exact missing mathematical law
```

`T42` addresses only that narrower question.

## What kind of law is missing

The missing law is not:

1. an external basis-pair population rule,
2. an already exported `theta_1/theta_2` map,
3. an already exported `E_orient`,
4. an already exported strict-core selector source.

It would instead be one future law of the form:

```text
primordial informational carrier at the guarded source limit
  -> typed preorientation datum
```

with the intended downstream role:

```text
if such a law were later formalized,
then external basis-pair search would no longer be the first mandatory
closure-facing question;
the first question would instead become:
"what typed primordial preorientation datum is exported?"
```
