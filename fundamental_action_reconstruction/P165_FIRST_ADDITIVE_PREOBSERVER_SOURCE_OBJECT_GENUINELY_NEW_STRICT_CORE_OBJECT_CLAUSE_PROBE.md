
## Probe rule

The probe may succeed only if all of the following are true:

1. `N183` already reduces the next constructive move to one first
   admissibility-upgrade target,
2. the target is still anchored to the fixed additive preobserver attempt
   `S_preLM_additive_candidate_v1`,
3. `F34` still requires
   `genuinely_new_strict_core_source_object_required`,
4. no earlier admissibility clause has priority over that clause,
5. the result is stated only as a first clause-level test target, not as a
   satisfied admissibility verdict.

## Allowed conclusion

If the probe passes, the only allowed conclusion is:

```text

source-object attempt is reduced to the genuinely-new strict-core
source-object requirement
```

No stronger conclusion is allowed.
