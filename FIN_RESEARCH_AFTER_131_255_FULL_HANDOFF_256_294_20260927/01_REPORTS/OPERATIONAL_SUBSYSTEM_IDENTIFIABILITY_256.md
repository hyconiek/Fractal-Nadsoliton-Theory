## Primitive intervention algebra can reconstruct subsystem factors up to relabeling

Date: 2026-09-27

This report replaces a purely semantic "record versus space" test by the operational criterion requested in the external audit.

Let Omega be a finite global state space and let E be a distinguished set of primitive reversible interventions.

Construct the NONCOMMUTATION GRAPH Gamma(E):
- vertices are primitive interventions;
- two vertices are adjacent iff the corresponding transformations do not commute.

Let its connected components be

    C_1,...,C_m.

For each component define

    G_i = <C_i>,

the subgroup generated by that component.

For each i define the complementary subgroup

    H_i = <G_j : j != i>.

Let Pi_i be the orbit partition of Omega under H_i.

For a global state x define its operational signature

    Phi(x)
      =
      (
        [x]_(Pi_1),
        ...,
        [x]_(Pi_m)
      ).

## The operational factorization criterion

If:

1. primitive generators in different noncommutation components commute;
2. the signature map Phi is bijective;

then

    boxed:
    Omega
      congruent
    Omega_1 x ... x Omega_m

where

    Omega_i = Omega / H_i.

Moreover:
- G_i acts only on factor i;
- all G_j, j!=i, leave factor i unchanged;
- the factorization is reconstructed from operational transformations, not supplied coordinates.

## Recoding invariance

Under any global bijective recoding

    phi:Omega -> Omega,

all primitive transformations are conjugated:

    T -> phi T phi^(-1).

Commutators, component structure, orbit cardinalities and bijectivity of Phi are preserved.

Therefore the reconstructed factorization is identifiable only up to:
- global state relabeling;
- permutation of equal factors;
- internal relabeling of each factor.

That is exactly the appropriate operational notion of identifiability.

## Kill test

If the only primitive intervention is one global 27-cycle, the same procedure reconstructs:

    one 27-state factor,

not three trits.

Likewise, if all global permutations are admitted as equally primitive, the operational symmetry is too large to distinguish a preferred tensor decomposition.

Therefore:

    boxed:
    subsystem factorization is identifiable from a sufficiently structured primitive intervention algebra,
    but it is NOT identifiable from the bare state set alone.
