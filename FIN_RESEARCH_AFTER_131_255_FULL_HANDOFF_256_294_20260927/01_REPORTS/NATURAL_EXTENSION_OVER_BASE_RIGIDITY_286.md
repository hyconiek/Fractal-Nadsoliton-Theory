# NATURAL-EXTENSION-OVER-BASE-RIGIDITY-286
## Over the declared base process, the natural extension has no nontrivial shift-commuting automorphism that fixes the base projection

Date: 2026-09-27

Status:
exact measure-theoretic theorem;
finite exhaustive replay for q=2,L=3.

Let

    (X_hat, T_hat, pi)

be the natural extension of a measure-preserving base endomorphism.

By definition the natural-extension sigma-algebra is generated by the shifted
pullbacks of the base sigma-algebra.

Suppose C is a measure-preserving automorphism of X_hat such that

    C T_hat = T_hat C

and

    pi C = pi.

Then for every integer n and every base observable f,

    f pi T_hat^n C
      =
    f pi C T_hat^n
      =
    f pi T_hat^n.

So C fixes every shifted base observable.

Because these observables generate the natural-extension sigma-algebra,

    boxed:
    C = identity

almost everywhere.

## Meaning

The natural extension is therefore RIGID OVER THE BASE:

once the base process and its factor map are fixed, there is no nontrivial
shift-commuting recoding that leaves the entire declared base process untouched.

This resolves an ambiguity left in report 281.

Shift automorphisms that mix neighboring records can exist, but they necessarily
change the base factor projection.

They are not automorphisms of the natural extension OVER the same declared base.

## Finite replay

It is the identity permutation.

## FIN consequence

Relative to the accepted stochastic state observable, record identity along the
natural-extension history is much more canonical than previously stated.

The shifted records

    pi,
    pi T_hat,
    pi T_hat^2,
    ...

are fixed by the extension structure itself.

## Boundary

This does NOT prove:
- that the chosen coarse Z3 state is ontologically fundamental;
- that history records are spatial sites;
- that a finite approximation must preserve every natural-extension coordinate.

But it does remove the worry that arbitrary state-dependent recoding is an equally
valid realization of the SAME extension over the SAME base.
