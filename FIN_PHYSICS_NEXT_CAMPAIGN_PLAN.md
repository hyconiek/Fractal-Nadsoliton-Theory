## Mission and scope

Freeze the MP7 reference interface, then ask which additional structures make
it a predictive physical model. Prioritize derive > assume > fit and
falsifiable bridge > analogy. Do not sharpen g_eq, Target S or irrelevant saddle
catalogs unless a named downstream prediction requires it.

recoverable local transformations, nontrivial influence structure and stable
coarse geometry **without silently importing their physical interpretation**.
The existing static core does not supply a unique composition law. Failure
to derive one must produce an explicit conditional model or a no-go, not a
renaming of the chosen law as emergent.

## Execution and resource rules

Write new results under `fin_physics_campaign/`; preserve all predecessor
files and AGENTS.md. Each modelling addition gets a PM ID before use. Report
exact assumptions, commands, seeds, tolerances, dependencies, rejected routes
and computational resources. Separate execution DONE from scientific PROVED.

- S: bounded analytic/exact finite check; normally <=5 min/run, <=2 GiB.
- M: controlled enumeration or modest numerical scout; <=30 min/run, <=4 GiB.
- L: one checkpointed proof/scaling experiment; <=2 h total per task, <=6 GiB;
  plan/resume in subjobs <=30 min. No unlimited runs or automatic size escalation.

These are computational ceilings, not promises about how long a difficult
proof takes. Use one heavy worker by default; no external compute, installation,
uploads, apparatus purchase or data collection without separate authorization.
Default exploration grids must be frozen before looking at results. Stop after
two failed method attempts with the same cause unless a new idea changes it.

Acceptance of a counterexample is distinct from acceptance of the proposed
positive hypothesis. A timeout or failed sufficient bound is INCONCLUSIVE.
Every lane ends with PASS_IN_SCOPE / REFUTED_IN_SCOPE / OPEN_WITH_ATOM / SKIPPED.
