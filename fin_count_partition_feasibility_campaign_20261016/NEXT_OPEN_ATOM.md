# FP-002 UNIFORM NATIVE PHASE FLOW: one still-open lemma

For all sufficiently large `N in 12*N`, with fixed exact `g_c` and real original MT `D_N`, find one `C<infinity` independent of N and weights `c_{xy}>=0` on **same frozen A/B phase**, legal single-copy count edges, satisfying

`sum_{y>_m x} c_xy -sum_{y<_m x} c_yx=(N/2) W_x d_native(x)`;

`sum_y c_xy <= C N W_x` at **every** vertex, with same-phase edges only.

Alternatively prove these requirements impossible for every possible fixed C eventually or along a subsequence decisive for the all-N existence proposition, with an exact dual/structural certificate. The new continuum bound `C>=g_B(0)/4>1/2` does not give impossibility because the class permits any fixed finite C. A numerical fixed-N LP failure is not an asymptotic answer.

Do not alter epsilon, p(z), T(z), MT energy threshold or label an artificial domain as D_N. If a genuine construction is ever admitted, then and only then start FP-003's conditional-time Jensen inequality and possible strict-positive mixture with its coupling error.
