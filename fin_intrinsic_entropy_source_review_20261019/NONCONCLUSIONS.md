# Nonconclusions and stop lines

No assumption that the primordial nadsoliton is finite-dimensional, finite-KS,
stationary, Hamiltonian, stochastic or described by an external model clock.
No derived unique generator, kinetic activity, nonlinear tensor, state space,
composition law, geometry, physical units/clock or calibrated records.

No impossibility of arbitrary deterministic representations or finite-window
approximation. The theorem uses full stationary sampled-history joinings,
deterministic readout and a common finite source-entropy budget. No optimal
rate-distortion function, sharp floor, achievable source or universal bound
over unbounded H/g is established. Changing definitions of entropy or using
an eigenvalue histogram does not test the same theorem.

Infinite dimension/singularity alone is not a pass; finite-H members remain
covered. No H bound for the whole NS/RP PDE is proved. A target-constructed
path-space flow escaping the finite-H class is not an independent source.
No positive-KS-to-thermodynamic-arrow inference or generic irreversible law.

No source archive/pasted-file custody, original-version equivalence or web
access is retrospectively certified. Replays and23 bounded controls are not
formal proof verification, independent peer review or empirical evidence.
No RP004/MH/B4 campaign, new source inventory, bath, random instrument,
selector/legacy-role, FIN-M0/task335/337 or QM/GR/SM/L_total/ToE activation.
