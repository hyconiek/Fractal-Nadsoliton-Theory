### B1. Character closure + rank selection → observable-algebra obstruction

The seven retained features plus constants span eight dimensions. A
translation-equivariant unital algebra of functions corresponds to an invariant
partition; block counts in a transitive twelve-label system cannot be chosen
freely. The retained primitive character also generates missing modes under
products. SRC-001 tests the resulting exact obstruction. It does **not**
invalidate the seven-parameter Gibbs family: addition of log densities is
not closure of all observable products. This distinction identifies a smaller
missing object than “derive rank seven from everything.”

### B2. Static subdivision + inertia → dynamic memory, not automatic closure

Eliminating an interior massive node produces a frequency-dependent boundary
map. Repeated refinement can create more visible poles even though static
resistances add exactly. REF-002/003 test closure and classify the necessary
passive response type. This builds on, rather than rediscovers, the existing
finite Schur-memory and zero-frequency nonidentifiability results.

### B3. Intrinsic cyclic order + 1D Schur no-go → circular-planar realization test

Pure chain subdivision cannot generate the nonnearest strict shells. The
recovered cyclic order nevertheless gives a non-arbitrary boundary order for
a **circular-planar response** compatibility test. REF-004 applies exact
circular-minor criteria to the full strict operator, after correcting current
sign conventions. This is a specific extension of the failed chain class,
not an assumption that space is two-dimensional.

The characterization is stated in Theorem 2.2.6 of
[Alman–Lian–Tran](https://arxiv.org/html/1309.2697#S2.SS2.Thmthm6), following
the earlier electrical-network results. Its convention has nonnegative
off-diagonal response entries; the positive-diagonal FIN Laplacian must not
be inserted with the wrong sign. Existence does not imply a unique network
or physical hidden geometry.

### B4. Entropy symmetry breaking + Fisher information → a mesoscopic window

For amplitude r, the known phase-dependent entropy correction is O(r^3),
whereas local statistical phase information often scales as n r^2. The new
target is a regime with `N r^3 -> 0` and `n r^2 -> infinity`. If n=N, the
candidate window is `N^-1/2 << r << N^-1/3`.

PHA-003 must pay preparation, angular measure, radial conditioning and
coherence lifetime; n (measurement count) is not silently N (copy count).
Success would establish observable approximate internal symmetry, not a
stable higher-dimensional spatial phase or a protecting source law.

### B5. Probability jets + elimination of latent time → escape–profile curve

Let `S(t)=sum_(j!=i) p_ji(t)` and `r_j(t)=p_ji(t)/S(t)`. For the declared
unitary and zero-velocity wave readouts, the leading destination profile is
the same `r0_j=A_ji^2/V`, with `V=sum_(j!=i) A_ji^2`.

The expansion suggests

```text
unitary: S=V t²+O(t⁴),       r-r0=O(t²)=O(S),
wave:    S=V t⁴/4+O(t⁶),    r-r0=b t²+O(t⁴)=B sqrt(S)+O(S).
```

For the full circulant strict A, vanishing of the entire leading wave shape
coefficient would impose `(A²)_ij/A_ij=constant` off diagonal. Circulant
diagonals and A1=0 then reduce this to an exceptional quadratic spectral
relation. The multi-eigenvalue strict operator is a natural nonexceptional
candidate. OP-002 must prove the precise statement and finite-window errors.

The curve removes the time parameter, so a monotone nonlinear control clock
need not obey the locally linear relation of CHANNEL-04. It does **not**
remove detector calibration or low-signal sample cost. A rough noise analysis
may make attempts scale like S^-2, worse than clock-calibrated tests. The
premise reduction, not an assumed sample reduction, is the proposed gain.
The exceptional equal-weight graph and full-record wave readout are mandatory
negative controls. Arbitrary hidden processes may reproduce the same curve;
the claim is only among stated channel classes.

### B6. Broad null geometry → limits of one-reset universal e-betting

The broad featured-rank null contains rank-one point-mass laws, or their
full-support limits. For a one-reset factor required to satisfy
`sup_Q E_Q e <= 1` for every admitted Q, this can force `e(y)<=1` pointwise.
MEM-003 tests the exact conditional/history quantifiers and the pair-matched
exception. It does not rule out batch e-values or test processes dominated
under each fixed null. It explains why a new betting formula alone cannot
magically fix weak composite evidence.

### B7. Safe likelihood upper bound → composite inference without a global MLE

On a fresh test batch, a normalized learned numerator divided by **any proved
upper bound** on null likelihood can be valid. An attained global maximum is
not necessary; a local EM value has the wrong bound direction. This route is
supported by the split-likelihood framework of
[Wasserman–Ramdas–Balakrishnan](https://arxiv.org/html/1912.11436v4).
MEM-005 must still obtain a tight enough upper bound and pay sequential reuse.

A critical scope distinction: `rank(T_F Q T_G^T)<=3` for the featured 4x4
matrix can admit more tables than `rank(Q)<=3` for the raw 9x9 table. Optimizing
only nonnegative-rank-three block mixtures does not upper-bound the larger
featured-rank null. Positive HMM realizability is a further issue, not a synonym.

### B8. Calibration maps + predictive rank → detector-memory attribution

A memoryless observation channel acts linearly on word blocks and can preserve
rank when the appropriate maps are invertible. A detector with state or
length-dependent postselection can create different visible behavior.
OP-004 links calibration with realization theory, proving what can and cannot
be attributed to the FIN system. Retaining all attempts is essential but does
not by itself establish independent resets or memoryless detection.

The five dominant problems are the source/type of the retained state algebra,
the full operator refinement law, the temporal/readout/hidden-memory interface,
controlled nonlinear propagation, and independent physical observation. All
future priorities should be judged by whether they remove one of these, expose
a necessary new object, or falsify an interpretation. A defensible stop at a
mathematical/statistical model is preferable to unlimited semantic promotion.

## Reproducibility of this design

The [specification and renderer](fin_post_phy_review/build_program.py) validate
all task fields, claim types, source references, priorities, wave order and
DAG acyclicity. [Search evidence](fin_post_phy_review/search_index.json) and
[selected source hashes](fin_post_phy_review/selected_sources.json) identify
the reviewed content. The authoritative AGENTS.md is unchanged; this programme
does not silently accept all imported candidate claims or start research jobs.
