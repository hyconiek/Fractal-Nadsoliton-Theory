## Abstract

Release 10.14 executes thirteen mathematical and operational research
programs. It tests whether modular theory, maximum entropy, or Morita
equivalence can select the missing sector state producing the strict damping
exponent, formally upgrades the fractional calculation, and constructs
detector, preparation-resource, bridge, and pre-data experimental objects.

For the sector algebra \(\mathbb C^5\), every continuous one-parameter
automorphism group is trivial, so every state is KMS. In the noncommutative
block enlargement, every faithful state defines its own modular flow. A
block-Gibbs family produces \(\eta=9/5\) only after the modular gap is fixed to
\(\log2=\alpha_{\rm geo}/4\).

Maximum relative entropy returns its chosen reference measure:

\[
\eta_{\rm sector}=\frac95,\qquad
\eta_{\rm Hilbert}=\frac{17}{9},\qquad
\eta_{\rm HS}=\frac{33}{17}.
\]

Morita-equivalent block amplifications also change the normalized Hilbert
central state. KMS theory, entropy, and Morita equivalence therefore do not
select \(w_2=1/5\) without an additional state-selection premise.

A 42-decimal-place interval FFT with analytic cell and tail bounds formally
covers every frequency in

\[
[10^{-3},2\cdot10^{-2}].
\]

All 50 cells have positive symbol lower bounds and are compatible with the
\(C|q|^{4/5}\) prediction. The maximum formal relative-remainder upper bound
is \(1.08135\), so the earlier tight \(2.2647\%\) floating-point result is not
yet formally recovered.

The certified continued fraction

\[
\frac{743}{4000\pi}
=[0;16,1,10,2,67,2,2,5,1,2,928,\ldots]
\]

provides a finite Denjoy–Koksma/Ostrowski discrepancy modulus through
\(N=10^6\). It does not provide an all-scale power rate.

The release constructs:

- Sobolev \(H^s\), \(s>1/2\), pointwise fractional-wave records;
- Gaussian detector-resolution operators;
- an exact joint inverse for fractional exponent, detector error, and memory;
- a calibration-invariant IQR spreading statistic;
- a reflection-asymmetry preparation resource theory;
- a strictly convex coupled state–damping action family;
- a typed legacy-to-strict completion diagram;
- an immutable pre-data physical protocol.

The preparation monotone

\[
M(\rho)=\frac12\|\rho-R\rho R\|_1
\]

cannot increase under reflection-covariant operations. For every
reflection-odd receiver \(C\),

\[
|\operatorname{Tr}(\rho C)|
\le M(\rho)\|C\|_\infty.
\]

Thus a symmetric state cannot generate a signed branch through symmetric free
dynamics. QW-2191 remains open.

Amplitude projectivization and conditional damping commute with strict only
when the oscillatory numerator is artificially shared. For actual canonical
legacy and strict phases/frequencies, the relative residual is \(0.470865\).
The phase/frequency and role-transfer arrows remain absent.

No external data are admitted.
