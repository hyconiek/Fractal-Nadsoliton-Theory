## 1. The missing gap is available without a new premise

Work in L²(pi), or its equivalent Euclidean reversible representation.
Let E_i be the conditional expectation given all copies except i. A true
Gibbs heat-bath refresh is exactly E_i. Each E_i is an orthogonal projection,
so 0 <= E_i <= I. The generator is

    S = E_1 + E_2 + E_3 - 3I.

Here and below E_i denotes its reversible representation when S is used.
The resolved projection P=UU^T is **E_3**, because the observation retains
copies1 and2 and hides only copy3. Thus Q=I-P satisfies QE_3Q=0. On Ran(Q),

    H = -QSQ = 3I - Q(E_1+E_2)Q,
    I <= H <= 3I.

This is an operator-order proof, not an eigenvalue computation. It needs no
new A7 source, no tuning of gain and no large-N result. The two comparisons
obey it too. Their heat-bath operators need not commute.

If the declared refresh rates are nu_i, the same argument gives
nu_3 I <= H <= (nu_1+nu_2+nu_3)I. The lower bound is therefore paid by the
**supplied kinetic law and rate**, not a derived physical clock.

Do not transfer the bound to Metropolis/Barker kinetics, simultaneous
deletion of several single-refresh copies, arbitrary coarse observations,
or a model without a full conditional hidden-refresh term. Those have
different projections/operators and require separate arguments.

## 2. Memory and preparation tails

For C=QSU and K(t)=C^T exp(-tH) C, spectral calculus gives

    exp(-3t) C^T C <= K(t) <= exp(-t) C^T C,
    M0 = integral_0^infinity K(t)dt = C^T H^(-1) C,
    M1 = integral_0^infinity t K(t)dt = C^T H^(-2) C.

In particular,

    (C^T C)/3 <= M0 <= C^T C,
    (C^T C)/9 <= M1 <= C^T C,
    integral_T^infinity K(t)dt <= exp(-T) C^T C,
    integral_T^infinity t K(t)dt <= (T+1) exp(-T) C^T C.

These are Loewner inequalities; they do not assert positivity of every
off-diagonal entry. For every fixed resolved vector a, a^T K(t)a is
completely monotone: (-1)^n d^n/dt^n [a^T K(t)a] >= 0. It is a nonnegative
mixture of decaying exponentials supported on rates in [1,3].

The inhomogeneous preparation contribution obeys

    ||C^T exp(-tH)b0|| <= ||C|| exp(-t) ||b0||.

A stationary kernel still cannot replace b0. The bound concerns the
orthogonal hidden block, not the spectral gap of the entire parent or the
relaxation rate of the full coupled resolved/hidden system. In particular,
it does not exclude slower resolved collective dynamics.

An exact undamped oscillatory scalar memory kernel or an asymptotic
algebraic memory tail would contradict this specific contract. A change
of microscopic kinetics/observation might evade it, but must receive a new
model ID and an independently motivated premise. No particle, inertia,
causal cone or physical propagation follows from this dissipative kernel.

belongs to the exact hidden space and r=c-H xhat, the gap gives

    ||x-xhat|| <= ||r||,
    |c^T x-c^T xhat| <= ||c|| ||r||,
    | ||x||²-||xhat||² | <= 2||xhat|| ||r|| + ||r||².
