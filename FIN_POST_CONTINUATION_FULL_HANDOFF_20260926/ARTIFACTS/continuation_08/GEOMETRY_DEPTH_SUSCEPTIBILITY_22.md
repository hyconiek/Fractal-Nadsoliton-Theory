## Exact recursion

For any node state, write its partition function as a mixture over root branch
alternatives `r` with log weights `l_r(alpha)`. Treat the equal-child unordered
correction as its two exact subbranches: the independent-product branch and the
diagonal branch. Then

    d2 log Z / d alpha2
      = Var_r(l_r') + E_r[l_r''].

Apply the same identity recursively to every child. This yields a nonnegative
level decomposition

    d2 log Z / d alpha2 = sum_{d>=0} V_d,

where `V_0` is variance due to choosing the current root split and `V_d` for
`d>0` is the conditional contribution inherited from depth `d` below it.
Therefore

    C_H = alpha^2 sum_d V_d.

alpha derivatives, and the complete depth vector in one recursion.
