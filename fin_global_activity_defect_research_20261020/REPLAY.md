The new standard-library checker uses Fraction arithmetic and exact outward
log intervals. It checks first-corrector/Taylor identities, actual positive
flow localization, scalar Hellinger inequality and a boundary-omission
negative control. The rational circulant field fixture is NOT actual A7;
small flow controls are not asymptotic MT simulations or an all-type proof.

--record authors only this fresh directory. --check writes only the explicit
/tmp output, preserves source hashes and verifies JSON/AST/links/manifests.
No historical scientific writer, external website, physical experiment,
independent agent or commit is part of these commands. A PASS is bounded
diagnostic/integrity evidence, not the independent proof audit in the next
order. All current statements are conditional/self-audited in that scope.
The first output-serialization failure and its bounded outward-rounding
repair are retained in [VERIFICATION_NOTES.md](VERIFICATION_NOTES.md).
