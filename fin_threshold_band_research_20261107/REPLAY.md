# Replay

From the repository root, run with Python and NumPy.

```sh
python fin_threshold_band_research_20261107/check_bands.py
```

The script records the NumPy version, twelve exact-integral budget
examples, two Fourier-grid identity checks and predecessor hash checks.
Its projected Gaussian snapshot is a finite comparison field. The
uniform and actual-component arguments are in PROOF_OR_OPEN_LEMMA.md.
The tests do not certify those infinite-dimensional proofs.
INPUTS.json pins source files and MANIFEST.json hashes the package.
