recurrence in Fraction polynomials modulo i^2+1. It checks the all-k,l
factor identity, Hermitian/parity properties, threshold rows/columns,
source moments, initial energy coefficients and resonant countercontrol
algebra. Finite samples are explicitly separate from symbolic identities.

RESULTS gives the actual algebra flag count, source-input count and
protected manifest-entry count. The script also checks own coverage,
Python/JSON syntax, Markdown links and whitespace. It excludes fenced,
inline and indented code before parsing prose links. These checks are
not certificates of the weighted dispersive proof or full PDE bootstrap.

`--record` authors metadata only for this fresh packet; it must not be
used to reseal a predecessor. Original checkers/scientific writers are
not run in place. No network, browser, cache, agent or heavy algebra is
required for replay. The exploratory bounded SymPy factorization is not
a dependency of the standard-library replay or analytical proof.
