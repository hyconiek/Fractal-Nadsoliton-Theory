# MP7 finite next atoms

The 48-task campaign has terminal dispositions. The following are deliberately retained as finite follow-up questions rather than hidden inside a “complete” label.

1. **Finite-N global quantitative remainder.** Prove an explicit outside-cap mass bound and a uniform error for moving minima in `g=g_eq+c/N`. The leading global logistic law is already proved; what remains is a practical theorem with explicit finite `N`.
2. **Target S.** The sharp sigma-threshold problem remains distinct from Target P. Any attempt should reuse the normalized-margin machinery and must not relabel Target P as Target S.
3. **D3 crossing nonlinear branches.** At the certified MP7-039 two-dimensional crossing, compute/validate the cubic and quartic reduced coefficients and classify daughter branches under the actual D3 action.
4. **Independent implementation challenge.** MP7-045 proves clean-environment reproducibility with the same implementations. A genuinely independent checker/derivation for the g=3.7 exhaustion, first-transition exhaustion and global normalized margin would strengthen implementation independence.
5. **Sharpen perturbative robustness only if scientifically useful.** MP7-021 gives a very conservative guaranteed neighborhood. Larger neighborhoods require a dedicated perturbation theorem rather than interpretation of the current sufficient bound.
