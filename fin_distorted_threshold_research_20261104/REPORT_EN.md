# The actual potential adds an outgoing threshold-reference cascade

DT takes the next operator-level step beyond CS's homogeneous far-field
calculation. It retains the exact threshold state, potential and bound
projections. It derives a closed static odd response and an exact
second-harmonic subtraction into a nondecaying particular solution plus
an outgoing response to an explicitly localized source.

That localized residual has a nonzero on-shell transform throughout the
original parameter band. Its response has oscillatory outgoing tails.
Consequently the full-potential stationary threshold jet is not merely
CS's constant phase coefficient plus localized corrections. The radiating
intermediate harmonic has to be retained. This is a reference spectral
statement, not actual emitted power or a nonlinear damping theorem.

The shape projection is kept explicitly. The direct cubic even projection
is also calculated; its localized threshold defect equals -27/35. This
uses convergent subtracted integrals and does not assign a finite value
to the divergent integral of r0^4.

The new formulas identify the next missing bridge: a finite-energy,
near-threshold packet/history estimate with the outgoing intermediate
harmonic included. No bound on the complete actual cubic trace is claimed.
ML's whole local-continuum O(epsilon) estimate remains unchanged; the
O(epsilon^2) target and three-channel action errors are still open.
