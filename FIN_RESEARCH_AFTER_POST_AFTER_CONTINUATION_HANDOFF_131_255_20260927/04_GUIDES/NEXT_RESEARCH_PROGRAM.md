# NEXT RESEARCH PROGRAM AFTER REPORT 255

## P0 — RECORD-TO-SPATIAL-ROLE-TRANSFER-256

Goal: find an operational criterion that distinguishes a bank of future information records from multiple simultaneously existing subsystems without importing external coordinates.

Test candidate criteria already meaningful in FIN:

1. **Commuting local observable algebras**: can the minimum-capacity `Z3^m` record factorization support independently addressable observables at one global history slice?
2. **Independent intervention access**: can one factor be perturbed while holding the others fixed, and does the resulting response remain internal to the same slice rather than merely altering future record order?
3. **Bidirectional same-slice response**: spatial neighbors should be able to influence one another through retained reversible dynamics; pure future-record scheduling is intrinsically one-use/ordered.
4. **Permutation/role invariance**: the criterion must not rely on labels such as “record 7” or a supplied coordinate.

Acceptance criterion: derive a typed property that a pure memory register fails and a genuine simultaneous multiunit carrier passes.

Negative result is valuable: if every such criterion requires a predeclared factor tensor structure, state explicitly that simultaneity remains an extra axiom.

## P0 — SLOT-ALGEBRA-257

If 256 identifies an operational simultaneous-subsystem criterion, classify the smallest reversible transformation algebra satisfying it for Z3 units.

Questions:

- Is SWAP still uniquely selected locally?
- Do pairwise gates generate a nontrivial locality algebra?
- Can incidence be reconstructed from commutation/noncommutation of **gates on slots** without falling back to the complete-graph copy no-go?

Do not assume a graph in advance.

## P0 — INCIDENCE-FROM-TRANSFORMATION-COST-258

Use transformation costs/barriers rather than coordinates.

Generalize the successful single-cell minimum-bottleneck test:

- define candidate elementary simultaneous transformations;
- assign their costs from the same microscopic/effective action;
- find the minimum-cost set generating connected accessibility;
- test uniqueness/stability under perturbation.

Only after a simultaneous carrier exists may the result be interpreted as candidate spatial incidence.

## P1 — DIMENSION-FLOW-259

Conditional on 256–258, test whether the number of independently required elementary transformations changes with scale.

Use:

- Cayley rank / generator independence;
- low-frequency Laplacian spectrum;
- heat-kernel spectral dimension;
- resistance growth.

Do not define dimension solely from group factor count.

## Parallel memory lane

Preserve the user's earlier requirement to track memory decay.

Do not merely quote M0/M1. At each new coarse level record:

- memory kernel spectral support;
- coupled hidden gap, not just global hidden gap;
- M0 and M1;
- integrated self-energy relative to direct drift;
- memory horizon needed for declared tolerance;
- preparation dependence / initial slip.

A proposed spatial hierarchy fails if memory remains comparable to the next-scale transition time without being retained explicitly.

## Stop conditions / guardrails

Stop a route if it requires inserting, independently at every scale:

- a new graph;
- a new free dimensionless coupling;
- a new clock;
- an arbitrary committor threshold;
- or a new semantic identification of state alternatives with spatial sites.

Prefer a clear no-go over adding another phenomenological parameter.
