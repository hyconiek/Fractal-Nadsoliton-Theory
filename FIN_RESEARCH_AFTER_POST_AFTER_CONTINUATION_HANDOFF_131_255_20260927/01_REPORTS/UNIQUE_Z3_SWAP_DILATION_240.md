# UNIQUE-Z3-SWAP-DILATION-240
## Under natural FIN symmetries, the reversible deterministic dilation of the Z3 MaxEnt reset is uniquely the swap gate

Date: 2026-09-26

Status:
exact finite-state theorem, independently exhaustively checked.

The effective Z3 generator can be written as a Poisson full reset:

    Q3
      =
      rho(U-I),

where

    U_ij=1/3

and

    rho=3k=|lambda_Z3|.

A one-step reset can therefore be generated by coupling the system trit x to a
uniform environment trit e.

Seek a deterministic gate

    F:Z3×Z3 -> Z3×Z3

with the following properties.

1. BIJECTION:
   global information is preserved.

2. EXACT RESET:
   for fixed x and uniform e, the first output is uniform on Z3.

3. UNIT EXCHANGE SYMMETRY:

       F tau=tau F,

   where tau(x,e)=(e,x).

4. DIAGONAL Z3 EQUIVARIANCE:

       F(x+c,e+c)
         =
       F(x,e)+(c,c).

5. MICROSCOPIC REVERSIBILITY OF ONE GATE:

       F^2=I.

## 1. Classification before imposing F^2=I

Translation equivariance lets us write, with d=e-x,

    F(x,e)
      =
      (
        x+u(d),
        x+v(d)
      ).

Exact reset makes u a permutation of Z3.

Exchange symmetry and global bijectivity leave exactly three possibilities:

    boxed:
    F_c(x,e)
      =
      (e+c,x+c),

    c in Z3.

So the only admissible gates are a swap followed by a common trit translation.

## 2. Involution selects c=0

Apply the gate twice:

    F_c^2(x,e)
      =
      (x+2c,e+2c).

Since 2 is invertible in Z3,

    F_c^2=I

requires

    c=0.

Therefore

    boxed:
    F(x,e)
      =
      (e,x).

The unique reversible symmetric reset dilation is SWAP.

## 3. Exhaustive replay

Among all 9! permutations of the pair state space:

    exact-reset bijections:

The survivor is exactly the swap permutation.
