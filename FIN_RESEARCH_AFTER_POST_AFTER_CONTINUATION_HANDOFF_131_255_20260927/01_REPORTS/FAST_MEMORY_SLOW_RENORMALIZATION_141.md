# FAST-MEMORY-SLOW-RENORMALIZATION-141
## Rapidly decaying memory leaves a large but controllable renormalization of the coarse generator

Date: 2026-09-26

Status:
exact finite-state spectral/projection calculation for N=3..6.

Projection:
three localized sectors plus one residual/transition class.

Let S be the self-adjoint reversible generator and write its resolved/hidden
block decomposition as

    S =
      [ A    C^T ]
      [ C     H  ],

where H=QSQ is negative on the hidden subspace.

The exact memory kernel is

    K(t)=C^T exp(tH) C.

## 1. Zeroth memory moment

Because the relevant memory decays, define

    M0
      = integral_0^infinity K(t) dt
      = C^T (-H)^(-1) C.

At low frequency the effective generator is therefore

    A0 = A+M0.

This correction is large.

For example at N=6:
- instantaneous coarse slow rate is about 0.1139;
- after M0 it becomes about 0.02325;
- the exact full-process slow rate is about 0.022611.

Thus short memory slows the coarse dynamics by roughly a factor five.

## 2. First memory moment

Define

    M1
      = integral_0^infinity t K(t) dt
      = C^T (-H)^(-2) C.

Expanding the exact memory self-energy at small Laplace frequency gives

    Sigma(z)
      = M0 - z M1 + O(z^2).

Therefore the long-time local equation is

    boxed:
    (I+M1) u_dot
      approximately
    (A+M0) u.

So memory renormalizes BOTH:
- the coarse generator;
- the effective kinetic/time metric.

## 4. Symmetry selection of memory

The globally slowest hidden eigenmodes are not the modes controlling this
memory kernel.

D12 selection rules suppress their coupling to C.

Therefore the correct memory time is controlled by the cyclic hidden subspace
generated by QSP, not by the global hidden spectral gap.

This is a central rule for subsequent FIN coarse-graining.

## 5. Meaning

A fast-decaying memory kernel must not simply be discarded.

Its moments survive as local effective coefficients.

This gives a concrete FIN example of:

    microscopic Markov dynamics
      ->
    short non-Markov memory
      ->
    renormalized local kinetic law.

It is a substantially stronger multiscale bridge than an exact-but-arbitrary
fiber generator.
