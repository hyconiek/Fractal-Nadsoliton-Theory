## The first dynamics-selected coarse level is three-sector, not binary

Date: 2026-09-26

The strengthened campaign now gives a sharper answer to the review question.

## 1. Binary local refinement did not survive the strengthened gate

- no recursive odd soft mode was found on the representative localized minimum;
- ±k6 is shallow and requires enormous N for a sharp barrier exponent;
- exact small-N committors overwhelmingly leak toward localized phases;
- parity is not strongly lumpable.

So the binary pitchfork remains a useful mathematical prototype, not the
preferred first effective unit.

## 2. The 3x4 hierarchy is dynamically selected

The same leave-one-out microscopic process gives:
- three symmetry-equivalent localized sectors carrying nearly all equilibrium
  mass;
- increasing inter-sector hitting times with N;
- negligible competition from the k6 basins at N=3..6;
- a two-dimensional slow spectral sector with very high overlap with the
  three-sector observable.

This structure was not imposed as a tree.

It was selected by:
- barrier ordering;
- equilibrium weights;
- committors;
- exact slow eigenmodes.

## 3. Memory is essential but controllable

The hard three-sector basin projection is not exactly Markov.

Naively using PLP overestimates the slow rate badly.

But the memory kernel:
- decays rapidly;
- has finite low moments;
- produces a systematic low-frequency expansion.

Keeping M0 and M1 gives

    (I+M1) u_dot
      approximately
    (A+M0)u

and reproduces the slow transition rate to 0.034% at N=6.

So the correct lesson is not

    "memory disappears".

It is

    "memory decays and leaves renormalized local coefficients".

## 4. Updated four-scale ledger

For every future coarse unit report:

    tau_mem:
      decay time of the COUPLED memory sector;

    tau_relax:
      intrabasin equilibration;

    tau_transition:

    tau_mem, tau_relax

If only the first inequality holds, a local effective generator may still
exist, but the chosen family is not an autonomous metastable unit.
