## The only incidence sourced by homogeneous exchangeability is mean-field and has no spatial hierarchy

Date: 2026-09-26

Status:
exact spectral/resistance corollary of report 153.

For n identical units without pair-specific relational data, the only
non-empty deterministic equivariant incidence is the complete graph K_n.

Its weighted Laplacian is

    L=w(nI-J).

Spectrum:

    0,
    n w repeated n-1 times.

Effective resistance:

    R_ij=2/(nw)
    for all i!=j.

## Why this cannot represent emergent local space

A local spatial graph should distinguish at least some pair separations.

K_n distinguishes none:
- every node is a neighbor of every other;
- every nonuniform mode has the same graph frequency;
- every pair has the same resistance distance;
- graph diameter is 1.

Rescaling w with n changes only the global rate/metric scale.

It does not create shells or locality.

Therefore the all-to-all exchangeable finite-copy structure already present in
FIN is mathematically compatible with mean-field thermodynamics but cannot, by
itself, be reinterpreted as emergent physical locality.

The missing ingredient is not “more copies”.

It is pair-specific relational structure.
