# INCIDENCE-IDENTITY-GATE-167
## The missing relational law must preserve more than edge number or node valence

Date: 2026-09-26

Reports 162-166 test increasingly strong conservation laws.

### Total edge number M

Gives sparse graphs if M=O(n), but leaves pair identity exchangeable.

### Exact local valence d_x

Fixes every node's number of neighbors.

Still leaves many inequivalent connected graphs.

The K3,3 / triangular-prism counterexample proves that even:
- equal valence;
- connectedness;
- vertex symmetry

do not determine the collective spectrum.

## What must now be sourced

A successful FIN relational law must constrain higher relational structure,
for example some combination of:

- cycle content;
- local path composition;
- holonomy/phase around cycles;
- pair-specific conserved flux;
- higher-order incidence constraints.

The crucial point is that such structure must distinguish WHICH neighbors are
related, not only HOW MANY.
