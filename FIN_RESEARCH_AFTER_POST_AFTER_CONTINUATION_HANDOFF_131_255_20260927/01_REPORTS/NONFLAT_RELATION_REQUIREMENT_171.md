# NONFLAT-RELATION-REQUIREMENT-171
## Nontrivial relational curvature requires an independent edge degree of freedom

Date: 2026-09-26

Status:
exact cohomological boundary in the finite-graph setting.

If every link phase is derived from node phases,

    A_xy
      =
      theta_y-theta_x,

then A is an exact 1-cochain.

Its cycle sum vanishes:

    sum_C A
      =
      0 mod 2pi.

So all curvature is zero.

To obtain nontrivial cycle holonomy one needs

    boxed:
    A_xy
      !=
      theta_y-theta_x

for at least some links.

That means the edge carries information not reconstructible from endpoint
states.

This is exactly the pair-specific relational degree of freedom demanded by
reports 153-167.

## Consequence

The phase/holonomy lane and the incidence lane now meet at one precise
mathematical object:

    an independent edge state.

Such an edge state could carry:
- activation;
- phase/connection;
- memory/storage.

But its:
- existence,
- sparsity,
- kinetic law,
- and coupling to node states

still need one common source law.
