# PROJECTED-MEMORY-DECAY-133
## Exact Mori-Zwanzig memory for the parity projection decays rapidly at N=3..6

Date: 2026-09-26

Status:
- exact finite-state computation for the declared leave-one-out Gibbs chain;
- N=3..6 only;
- no large-N uniform memory theorem is claimed.

## 1. Equilibrium projection

Work in L2(pi_N), where the reversible generator is self-adjoint after the
standard square-root-pi similarity transform S.

Let P be conditional expectation onto functions of

    Y = number of even-label copies,

and Q=I-P.

Using an orthonormal resolved basis B, define

    C = Q S B,

    H = Q S Q.

The exact projection-operator memory kernel is represented by

    boxed:
    K(t) = C^T exp(t H) C.

The quantity reported below is

    ||K(t)||_2 / ||K(0)||_2.

## 2. Direct decay

    N=3:  1.090

The N=6 tail is therefore consistent with a memory time of order

    tau_mem ~ 1/0.69 ~ 1.45

in microscopic refresh-time units.

## 3. The global hidden gap is NOT the memory-decay rate

The slowest eigenvalues of the hidden operator QSQ are much closer to zero:

    N=3: gap ~0.12695
    N=4: gap ~0.06863
    N=5: gap ~0.03817
    N=6: gap ~0.02132.

Naively this would predict very long memory.

But the coupling of those slow modes to the memory source C is numerically
tiny, around 10^-25--10^-31 relative to the K(0) operator scale.

## 4. Symmetry explanation

The exact Gibbs law and generator are D12-equivariant.

The subspace of functions of Y is itself D12-invariant:
- even translations preserve Y;
- odd translations map Y -> N-Y;
- reflections act within the same resolved family.

Therefore P commutes with the D12 action.

Hence C=QSP can couple only to irreducible sectors already present in the
resolved parity representation.

Slow hidden eigenmodes in other D12 sectors are exactly symmetry-forbidden
from contributing to K(t).

This explains why the global hidden spectral gap can collapse while the
observable memory still decays rapidly.

## 5. Relation to earlier FIN memory mechanisms

This is a new projection memory generated by exact finite-N coarse graining.

It must not be identified with:
- the hidden Gaussian initial-slip kernel of reports 32-33;
- the moving-phase memory kernel of report 41;
- internal network-storage memory.

All can decay, but they arise from different eliminated variables.

## 6. Consequence

Memory cannot be ignored exactly, but it is not automatically long-lived.

For the tested small N the parity memory decays on an O(1) time scale, much
faster than the near-critical mean-field k6 relaxation time

    tau_relax ~118

at g_opt.

If an O(1) coupled-sector memory gap survives at large N, an approximate
Markov reduction after a short initial-slip window becomes plausible.

That survival is now a required large-N test.
