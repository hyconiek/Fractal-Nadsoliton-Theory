# CONTROLLED-MULTISCALE-DYNAMICS-PROGRAM-135
## Updated programme after the strengthened 131/132 tests and explicit memory decay

Date: 2026-09-26

The new campaign should no longer search blindly for more stationary branches.

The central object is one exact microscopic process:
the leave-one-out Gibbs heat-bath.

## P0-A — Capacity-controlled metastable unit

Use the actual full-X7 basins of:
- +k6,
- -k6,
- the competing localized phases.

Compute capacities / committors for the exact finite-N process or rigorous
large-N bounds.

The immediate target is to replace the saddle-level criterion

    B_switch < B_escape

with a process-level statement about:
- hitting probabilities;
- mean exit times;
- switching rates.

The basin definition must be D12-equivariant and predeclared.

## P0-B — Coupled-sector memory-gap theorem

For the chosen coarse observable/basin partition, do NOT use the global hidden
gap.

Prove a lower bound on the spectrum of QLQ restricted to the cyclic subspace
generated by

    Q L P.

This is the sector that actually enters the memory kernel.

Success:
an O(1) lower bound uniform over the parameter/N window of interest.

Failure:
a coupled metastable hidden mode appears and creates long memory.

## P0-C — Controlled semigroup reduction

Prove or numerically bound

    sup_(0<=t<=T)
    || P exp(tL) J - exp(tL_eff) ||

for a physically relevant window T.

If a Markov approximation is insufficient, retain the derived memory kernel
instead of forcing closure.

## P0-D — Abandon unrestricted local binary refinement

Report 131 found no reflection-odd soft mode on the representative main
localized minimum from g=3.516 to 50.

Do not continue an unbounded search for recursive pitchforks.

Instead derive the hierarchy from actual metastable partitions:
the existing 3 sectors x 4 states are a natural first candidate.

Binarity is allowed only if the dynamics selects it.

## P1 — Memory-decay scaling

Extend exact finite-N calculations beyond N=6 using:
- symmetry quotienting;
- Krylov methods;
- sector-restricted spectral calculations.

Track separately:
- total hidden gap;
- coupled-sector gap;
- integrated memory norm;
- semigroup closure error.

This directly implements the user's requirement that later stages account for
memory decay.

## P1 — Nonstationary preparation

After a metastable coarse model is fixed, merge it with reports 32-33:
compare short projection memory against preparation-dependent hidden memory.

The two mechanisms must be distinguished experimentally/mathematically.

## P1 — Alternative hierarchy

If the parity-bit route remains too weak or requires enormous N, promote the
three four-state metastable sectors as the next coarse units.

Then derive their effective generator from capacities and test the same
memory-decay criterion again.

The goal is a hierarchy selected by time-scale separation, not by a prescribed
binary tree.
