# FIXED-CYCLE-PENALTY-NOGO-181
## A fixed energetic preference for fewer permutation cycles still does not select one connected component at large n

Date: 2026-09-26

Status:
exact weighted-permutation asymptotic.

Weight each permutation by

    theta^(K),

where K is its number of cycle components and theta>0 is fixed.

Equivalently, an O(1) energy penalty per cycle corresponds to fixed theta.

The partition function is the rising factorial

    Z_n(theta)
      =
      theta(theta+1)...(theta+n-1).

The total weight of one-cycle permutations is

    theta (n-1)!.

Therefore

    boxed:
    P_theta(K=1)
      =
      Gamma(theta+1) Gamma(n)
      /
      Gamma(n+theta).

For fixed theta>0,

    P_theta(K=1)
      ~
      Gamma(theta+1) n^(-theta)
      ->
      0.

So even a fixed energetic bias toward fewer components does not select a
single connected cycle with finite probability asymptotically.

To keep the one-cycle probability O(1), theta itself must approach zero with
n, roughly on a 1/log(n) scale.

That is again system-size-dependent tuning.

## Verdict

The two-port route solves topology uniquely IF connectedness is granted.

But connectedness is not generated by:
- uniform MaxEnt permutations;
- or a fixed O(1) per-component energy.

A deeper global conservation/topological law would be required.
