# Corrections and supersessions

1. **Equilibrium memory order**  
   Supersedes the predecessor's broad `N^-1/2 hidden memory` wording.  In a
   stationary heat-bath state the Gaussian residual hidden process decouples;
   after averaging it, the first genuine reduced feedback is `O(1/N)`.
   Generic non-equilibrium trajectories can still carry `O(N^-1/2)` hidden
   dependence.

2. **Skewness is not the first equilibrium signature**  
   All odd jump cumulants vanish at `p=q`.  The first useful equilibrium hidden
   signature is a fourth-order / quartic observable, not a third moment.

3. **Hierarchy entropy values**  
   Finite-depth values `h8~1.45493`, `h12~1.83771` are superseded.  The
   asymptotic recurrence gives approximately `h8=1.45222347`,
   `h12=1.83500618`.

4. **D_H=2 status**  
   `D_H=2` is not derived by generic self-similarity.  It is the marginal point
   selected only if one additionally requires unrescaled local conductances to
   remain uniformly bounded above and below through refinement.  Natural
   storage `M_d=b^-d` already gives `tau_d~ell_d^2` for every `D_H`, so dynamic
   self-similarity itself does not select dimension 2.

5. **Hierarchy stability**  
   A positive next-tree gap in a finite example is not enough to establish a
   thermodynamic ordered phase.  Full partition sums show substantial
   composition dependence, including near-degenerate phase mixtures.

6. **Kurtosis numbers**  
   Earlier `0.1100748/N * exp(-1.575498 t)` describes one hidden-memory kernel
   component for a k=5 quartic.  It must not be confused with the later exact
   short-time max-entropy-closure defect coefficient
   `0.093453912.../N` appearing in the third generator derivative.

7. **Eight-phase transition campaign**  
   The current 8-phase extension is still in progress.  Only initial scaling
   checks are retained as scouts; no thermodynamic conclusion is exported.
