# TWO-MEMORY-01 — operational separation of two memory mechanisms

Status: **CONDITIONAL_SYNTHESIS**

## Main result
Two mathematically distinct memory channels are now identifiable.  Geometric tree-bulk memory appears already in the linear matrix response as poles/residues.  Internal-state `p->mu` memory has no leading stationary linear-response pole and first shows a clean finite-N signature in nonlinear quartic statistics, especially k=5.  This suggests a target-blind two-stage diagnostic: reconstruct linear geometry first, then test excess fourth-order response with k=3,4,6 controls.
