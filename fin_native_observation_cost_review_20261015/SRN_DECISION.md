NOC closes a real native achievability bridge. It does not need a minimax
lower bound to become a useful effective statistical prediction. Source
necessity remains an optional mathematical question, not a physics blocker.

The selected next problem is a different operational bridge: eliminate the
cosine classifier's reliance on a known amplitude unit. Use the same block's
simultaneous null and kernel-sensitive features, and freeze

    H=1{|W3|>|W1|}.

It is pointwise invariant under a **common nonzero multiplier** of both
channels at each sample, even if that multiplier changes between samples.
It is not invariant under unrestricted independent channel gains or offsets.
Those nuisance distinctions must be proved, not silently assumed physical.

The raw event is nonsmooth. A native theorem needs anti-concentration of
W3+W1 and W3-W1, a mollifier used only in the proof, and an alpha-uniform
four-coordinate corrector bound. These are new obligations; the observer
must still use the raw invariant event rather than a scale-dependent smooth proxy.

Start SRN-001–003, then the separately frozen native decision gate. This
changes the readout and uses a more conservative asymptotic block sequence;
it does not improve or optimize NOC's cost exponents. No microscopic law is added.

The older reports148/154/200/202/203 already rule out the direct copy-as-space
shortcut; replaying that lane would not create physical locality. The present
work targets one real readout premise only. Kernel/kinetic source, units,
locality/conservation and empirical mapping remain independent missing bridges.
