# BR-001 replay recipe

The task is an **input audit**, not a numerical-science campaign.

1. Read `OBJECT_CONTRACT.json`, `ADMISSION_OR_OPEN_INPUT.md` and the plan file listed in `INPUTS.sha256`.
2. Check that the post-SRN plan's B07 object is explicitly absent and BR-002/003 are conditional on BR-001 admission.
3. Read the SRN handoff/next open atom for a genuinely *new* source, composition or empirically licensed interface object. The ideal angular statistic is not such an object.
4. Run `python verify_br001.py` in this directory. The script verifies required decisions and the self-contained manifest. If the external source paths still exist, run `python verify_br001.py --sources` for input hashes as well.
5. Do not convert absent remote AGENTS/review artifacts into a false negative audit of their unseen contents: `OPEN_INPUT` means not supplied in *these* materials.

The script verifies packaging and consistency, **not** the earlier SRN theorem or nonexistence of any conceivable new bridge object.
