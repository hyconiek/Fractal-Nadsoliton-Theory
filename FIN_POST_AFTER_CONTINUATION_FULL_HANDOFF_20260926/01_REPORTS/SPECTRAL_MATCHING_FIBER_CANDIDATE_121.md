# SPECTRAL-MATCHING-FIBER-CANDIDATE-121
## A unique fiber rate follows conditionally from equalizing fiber and slow coarse relaxation

Date: 2026-09-26

Status:
- exact conditional source candidate;
- the matching premise is NOT derived from FIN.

Let

    delta

be the coarse spectral gap.

In the two-child fiber, the antisymmetric mode has decay rate

    2mu.

Impose the additional naturality premise:

> a newly resolved binary fiber should relax on exactly the slowest
> already-resolved coarse time scale.

Then

    2mu=delta,

so uniquely

    boxed:
    mu=delta/2.

This rule has several attractive properties:

1. It is target-blind.
2. It is equivariant.
3. It is positive.
4. It scales correctly under a global clock rescaling.
5. It introduces no new slower mode.
6. Reapplying the same rule after refinement reproduces the same gap and the
   same mu at every level.

For the three-sector metastable quotient of report 116,

    delta_meta=3 k4.

Therefore the conditional prediction is

    boxed:
    mu_meta=(3/2) k4.

This is a genuine one-number source candidate.

However the equality

    fiber relaxation = coarse spectral gap

is an extra premise.

Other equally covariant choices exist, for example matching:
- mean escape rate;
- average positive eigenvalue;
- trace density.

So this report is a CONDITIONAL closure candidate, not a derivation.
