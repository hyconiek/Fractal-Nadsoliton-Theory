Meaningful continuation requires:
\begin{enumerate}
\item a new formula-level strict object passing all seven intake rows;
\item a new exact method for one open hard-math frontier; or
\item an external independent apparatus/record state change.
\end{enumerate}

This is not an absolute impossibility theorem for a future richer FIN object.
