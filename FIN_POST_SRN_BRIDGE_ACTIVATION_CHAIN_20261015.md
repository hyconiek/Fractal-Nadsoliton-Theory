Use this priority only when a concrete object is actually supplied:

1. **SOURCE:** a target-independent constraint, action, mediator or selection
   object predicting at least one kernel support/weight relation. Prefer
   deriving over assuming and fitting. A new principle introduced solely
   to reproduce the desired A7 is not an independent source theorem.

   beyond exchangeable regrouping, with its source variables and incidence
   rule. This can open a locality question but does not already prove locality.
3. **INTERFACE:** supplied operational records/law mapping for the two
   simultaneous features, or another explicitly licensed readout. This is
   an engineered bridge, never natural A7 selection merely because A7 is programmed.

No object is selected by this plan. No currently absent evidence is invented.

execution agent does not combine three new theories in one handoff.

identify the exact premise it changes or genuinely derives beyond that class.
A graph drawn around the same labels, covariance or Fourier modes does not
evade those results. Do not infer a theorem ruling out every future geometry.

For source, existing FAR/selector/legacy inventories remain repetition-gated.
Do not reopen one without a genuinely new typed source object and its specific
blocker-cut. Any authorized work under fundamental_action_reconstruction must
first read its mandatory kernel-split/current-frontier instructions.
