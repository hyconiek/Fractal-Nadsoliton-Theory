# A precise remaining physical atom: activation barriers, not equilibrium alone

Date: 2026-10-17. Conditional transition-state comparison, not an added FIN
microscopic premise. Physical beta and an energy identification are inputs.

Fix a cavity r, with visible free energies E_a=-h_a/beta up to a background
constant. The one-intermediate construction is Gibbs reversible when

    E_H=(1/beta)log(kappa/nu),
    k_aH=nu, k_Ha=kappa exp(-beta E_a).

A supplied transition-state description with attempt prefactor nu0 and
barrier B_a shared in both directions gives

    k_aH=nu0 exp[-beta(B_a-E_a)],
    k_Ha=nu0 exp[-beta(B_a-E_H)].

The complete-reset trace is obtained if **B_a-E_a=B0**, independent of a,
with nu=nu0 exp(-beta B0). It is this equal *relative* activation barrier,
not Gibbs detailed balance, which supplies state-independent activation.
Barrier height/prefactor and the intermediate free energy set the clocks.
They must be justified by an independent carrier or existing pre-Markov
equations; computing them backward from assumed HB is circular.

Mandatory countermodel: with one common **absolute** barrier B_a=B(r),
activation is C(r)exp(beta E_a) and all intermediate refills are equal.
The visible trace rate is C(r)exp(beta E_a)/12. It has the same conditional
Gibbs equilibrium by detailed balance, but is not the native reset law.
More general barrier/prefactor choices preserve the same equilibrium and
vary symmetric activity. A nonempty physical-provider claim must exclude
or constrain at least this freedom, not merely exhibit a convenient lift.

The primitive reaction model here is an analysis comparison. A physical
intermediate or global single-vacancy constraint has not been derived.
An action/quasipotential calculated from an already assumed HB generator
cannot independently source that generator's barriers or prefactors.
The earlier AS/KB/QP source gates therefore stay open. A genuinely new
barrier/coupling object would be admissible without external experiments,
but it must actually provide this missing dependency, not postulate it
under the old FIN identifier. Ontology and no-new-substrate rules remain.
