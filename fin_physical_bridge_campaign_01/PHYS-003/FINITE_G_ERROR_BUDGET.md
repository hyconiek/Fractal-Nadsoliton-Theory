# Finite-g error budget
Dla pochodnych użyto dokładnej enumeracji count states N=2,3. Przy g=0.2 maksymalna odchyłka od liniowej odpowiedzi jest ~1.04e-3 (N=2) i ~9.47e-4 (N=3). Pierwszy proponowany test walidacyjny używa jednak dokładnego N=2 pair histogramu, więc jego błąd „finite-g approximation” wynosi 0 w obrębie modelu; pozostają kalibracja i statystyka.
