# CC contract and exact model map

Date: 2026-10-21. Analytical, conditional, same-author study.
Authorization and all new premises are in
[AUTHORIZATION_AND_MODEL.md](AUTHORIZATION_AND_MODEL.md).

The primary object is the whole response rule h->R(h), not a single
generator at a fitted field. The new axiom applies to additive contributions
to the same conditional logit vector. It does not assert independence of
the processes constituting the nadsoliton.

For actual FIN counts n, a slot currently carrying a has background
r=n-e_a. Keep denominator N and set h=(g/N)A7 r. The candidate count rate is

    Q(n,n-e_a+e_b)=n_a R_ab(h).

For symmetric constant-diagonal A7 this conditional uses the original
Gibbs potential, including the count multinomial multiplicity in its
quotient. No N-1 denominator or missing diagonal correction is introduced.
Full finite labelled dynamics is used for exact identities. A reflected
restriction rejects departures, without renormalizing proposals. No
metastable initialization or asymptotic path theorem is newly asserted.

Quantifiers: q>=2, all finite h,u,v and shifts c, fixed model parameter when
one remains. The comparison with A7 uses any finite N>=2 and g>0 unless a
particular finite fixture is explicitly specified. N3 is a microscopic law
test, not an MT critical-domain example. Algebraic fixtures with another
matrix are not called actual A7 calculations.

The neutral 1/q convention only identifies clocks at h=0. Inherited SQRT
uses neutral off-diagonal rate 1; its generator is q times the s=0 model
below. Clock conversion is stated, never fitted to a positive-g outcome.
No previous HYP, HB, PDE, source package or AGENTS is modified.
