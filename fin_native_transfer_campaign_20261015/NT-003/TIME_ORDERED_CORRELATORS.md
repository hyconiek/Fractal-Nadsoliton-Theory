# NT-003 — Euclidean correlator dictionary

For bounded real or complex observation functions f_j on R and `0=t0<=t1<=...<=tk`, the stationary limiting process gives

`E_rho[prod_{j=0}^k f_j(Z_{t_j})]
 = <1, M_f0 S(t1-t0) M_f1 ... S(tk-t{k-1}) M_fk 1>_rho`.

After conjugation by `sqrt(rho)`, this equals

`<psi0, M_f0 exp[-(t1-t0)H] M_f1 ... exp[-(tk-t{k-1})H] M_fk psi0>_L²(dz)`.

The algebra is a statement about passive time-ordered classical random variables. Multiplication operators at fixed time commute and all readouts live on a common path probability space. Intermediate transfer and multiplication need not commute, but their abstract algebra is not an automatically licensed laboratory instrument. A formal `exp(-itH)` is mathematically definable; no physical real-time counterpart is derived.

Bounded finite native cylinders inherit these correlators on fixed critical windows through NT-002's stationary path hypotheses, and late iid readouts only by the declared MT labelled-TV/exit transfer.
