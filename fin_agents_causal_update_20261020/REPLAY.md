# Instruction revision and historical-context replay

From repository root:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 fin_agents_causal_update_20261020/verify_update.py --check --replay-archives --output /tmp/fin-agents-causal-check.json
PYTHONDONTWRITEBYTECODE=1 python3 fin_reversible_source_transfer_research_20261020/verify_research.py --check --output /tmp/fin-rs-check.json
git diff --check
```

The first checks the exact old and new AGENTS prefixes, matching append,
mutation/truncation negative controls, protected package hashes and this
manifest. Seven **read-only** old validators run in a temporary copy tree
with only the old verified AGENTS input restored. These passes are labelled
ARCHIVED_CONTEXT. A direct live ES checker is also run and must reject the
changed full-file hash. Do not advertise it as a live pass or rewrite its
historical dependency to make it green.

Each subprocess has a 60-second/1-GiB limit. Existing scientific scripts,
metadata writers and numerical results are not regenerated by this helper.
Only this new package's authoring --record mode writes its contract/results/
manifest. Later --check replay writes only to the requested /tmp output.

The existing older `fin_agents_update_20261019/verify_update.py` still binds
its own earlier prefix; a later append is correctly outside that earlier
review rather than a historical hash failure.
