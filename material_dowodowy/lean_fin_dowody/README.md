# Lean FIN dowody

Ten katalog zawiera root-level artefakty dowodowe i specyfikacyjne oznaczone prefiksem `FIN_`.

Zakres:
- `FIN_*.lean`
- `FIN_*.md`

Polityka kompatybilnosci:
- fizyczne pliki zostaly przeniesione tutaj,
- w katalogu glownym pozostawiono symlinki,
- skrypty `QW_*.py` pozostaja na miejscu jako warstwa wykonawcza.
