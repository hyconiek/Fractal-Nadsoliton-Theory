# State-dependent hierarchy at fixed r

Status: **CONDITIONAL_ARCHITECTURE**

## Result
Exact grouping energy alone is tree-independent, but after second-order
scale weighting E_H=sum r^(2d) Delta_v the degeneracy is lifted for r>1.
For four equal leaves the minimizing pairing is exactly the one with smallest
within-pair variance. This provides an S_N-equivariant rule for choosing
relations from state rather than preassigned positions.

## Key formulas
\[E_H(r)=\sum_vr^{2d(v)}\Delta_v,\quad
\Delta_v=\frac{N_LN_R}{N_L+N_R}\|\mu_L-\mu_R\|^2.\]

## Caveat
The rule is conditional; H is not yet a sourced physical degree of freedom.
