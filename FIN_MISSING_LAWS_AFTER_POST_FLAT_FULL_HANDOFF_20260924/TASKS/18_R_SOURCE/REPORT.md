# R-SOURCE — no-go for self-selection of r

Status: **NO_GO**

## Result
For fixed state and hierarchy, E_H(r)=sum r^(2d)Delta_v is monotone
nondecreasing in r, strictly increasing for a nontrivial state. The Gibbs free
energy over H is therefore also monotone. If r itself is minimized with no
competing term, the system selects the boundary r=1, not a nontrivial scale
separation.

## Key formulas
\[E_H'(r)=\sum_{d(v)>0}2d(v)r^{2d(v)-1}\Delta_v\ge0,\quad
F'(r)=\langle E_H'(r)\rangle\ge0.\]

## Caveat
No present strict FIN term counteracts this monotonicity.

## Next question
Only search for new terms/principles capable of favoring r>1.
