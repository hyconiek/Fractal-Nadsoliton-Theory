# Replay

From repository root, without bytecode caches:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 fin_reversible_source_transfer_research_20261020/search_prior.py --output /tmp/fin-rs-search.json
PYTHONDONTWRITEBYTECODE=1 python3 fin_reversible_source_transfer_research_20261020/verify_research.py --output /tmp/fin-rs-check.json
```

The first command searches a frozen, explicitly listed index selection and
reports exact matching paths/lines. It is not an exhaustive proof audit or
evidence that no provider can exist. No network is used.

The second uses stdlib Fraction finite matrices, hidden-prefix enumeration
and a separately derived three-state spectrum. Rational discrete kernels
test the finite-lag identity/bound; they are not claimed to be embedded
CTMC semigroups. The actual continuous-time example has its analytical
spectral proof. No finite fixture mechanically proves the general theorem.

Canonical RESULTS/SEARCH_RESULTS, input hashes and manifest are generated
only inside this new package during its authoring. Subsequent replay writes
to /tmp, preserving the sealed scientific evidence and old packages.
