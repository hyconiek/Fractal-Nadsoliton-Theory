# Replay

From the repository root run with Python and SymPy.

```sh
python fin_radiative_work_transfer_research_20261107/check_transfer.py
```

The script uses Laurent polynomials in two oscillator phases to extract
exact zero-frequency work coefficients. Real and imaginary susceptibilities,
including cross-profile responses, are kept as independent symbols.
The frequency inventory and a rational uniform gap bound are checked.
Finite tail norms use (1+t)^-1/2 and the analytic MA envelope budgets.
The output records SymPy's version and source provenance checks.

The finite controls audit algebra and power estimates. The actual-history
transfer and its scope are proved in PROOF_OR_OPEN_LEMMA.md.
MANIFEST.json hashes all package files except itself.
