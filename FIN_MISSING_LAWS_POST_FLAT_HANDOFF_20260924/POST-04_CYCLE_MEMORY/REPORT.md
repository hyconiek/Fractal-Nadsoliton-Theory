# POST-04 — CYCLE-MEMORY no-go

Status: **NO_GO_SYMMETRY_DOES_NOT_SELECT_MEMORY_COUPLING**

Complete C12 has a 55-dimensional cycle space and a 7-dimensional visible
moment-neutral quotient.  In the static Gaussian parent the canonical
regression separates the edge state into a visible minimal lift and a
divergence-free residual; that residual is independent of the visible
mediator.

`dim Hom_D12(cycle, visible) = 16`.

So symmetry does not forbid memory coupling, but leaves a large family of
equally covariant linear couplings.  The missing memory/inertia law cannot be
recovered from D12 alone.
