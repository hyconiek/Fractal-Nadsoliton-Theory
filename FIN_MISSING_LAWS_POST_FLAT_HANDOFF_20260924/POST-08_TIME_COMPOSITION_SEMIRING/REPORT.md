# POST-08 — TIME-COMP and the semiring gap

Status: **CONDITIONAL_QUADRATIC_KINETIC_GEOMETRY__SEMIRING_NOT_SOURCED**

If an additive evolution parameter tau is supplied and endpoint costs compose
by minimizing over an intermediate state,

`C_(tau1+tau2) = min [C_tau1 + C_tau2]`,

then a continuous quadratic family necessarily has precision `K(tau)=M/tau`.
The fine-partition limit is the standard quadratic path action.

If Q is an edge transfer and h=BQ, the same minimum-lift identity turns the
edge metric into the quotient metric A7^+ for hdot.

However a Gaussian transition kernel composed by integration
(Chapman-Kolmogorov, sum-product) has the same `Delta^T M Delta/(2 tau)`
quadratic exponent and leads to diffusion rather than inertial least action.

Therefore the new bottleneck is not mainly the tensor M.  It is the algebra by
which alternative histories are composed: probabilistic summation versus
variational minimization (or another rule).  Current FIN does not source this.
